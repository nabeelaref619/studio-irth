استخدام الأدوات

يمكنك استخدام الأدوات مجاناً للأعمال الشخصية والتجارية على الملفات التي يحق لك معالجتها. تحتفظ بحقوقك في ملفاتك ونصوصك؛ استخدام الأداة لا ينقل ملكيتها إلينا.

راجع النتائج واحتفظ بالأصل

الأدوات متاحة كما هي، وقد تختلف النتائج حسب المتصفح والجهاز ونوع الملف. لا نضمن التوافر المستمر أو خلو النتائج من الأخطاء. احتفظ بنسخ أصلية وافحص الملفات قبل النشر. توقيت الإلقاء تقدير حسابي وليس قياساً لتسجيل فعلي.

استخدام مسؤول

لا تستخدم الموقع لمحاولة تعطيل الخدمة أو الوصول غير المصرح إلى الأنظمة أو انتهاك حقوق الآخرين. لا تنسب للموقع ضماناً لجودة تجارية أو لتوافق مع كل منصة.

التحديثات

قد نعدّل الأدوات والمحتوى مع الوقت. تتضمن صفحة الخصوصية وصفاً لمعالجة البيانات الحالية. إذا لاحظت خطأ، أخبرنا عبر صفحة التواصل. لا تقصد هذه الشروط إلغاء حقوق لا يمكن استبعادها بموجب القانون المطبق.
